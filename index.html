02 · O QUE IMPORTA

Como otimizar

Peso de 0 a 5

Você controla o ranking pelos pesos; nenhum filtro adicional de atributos é aplicado.

Limites mínimos dos atributos

Esses limites são requisitos, não preferências. Se nenhuma build atender, ajuste ou remova um limite.

Aumente o peso para valorizar mais um atributo. Peso 0 ignora esse atributo no ranking.

Outros atributos

Progressão, utilidade e bônus adicionais também podem orientar a busca.

Skill points também contamDeixe como 0 se não quiser dar peso extra a esses bônus.
